# Rhythma — Blood (1997) style design prompt

Visual language of Monolith’s **Blood** (Build engine FPS, 1997): dark gothic pixel HUD / DOS menu chrome — mapped onto Rhythma’s dark neon palette.

Not gore. Atmosphere + UI grammar only (no corpses, weapons, violence).

## Palette (brand → Blood mood)

| Role | Hex | Blood mapping |
|------|-----|----------------|
| Void background | `#0A0A0A` | Pitch-black levels |
| “Blood” accent | `#FF10F0` | Classic blood-red role, neon brand pink |
| Cold secondary | `#5ECAD6` | Sickly/cold highlight (ammo/alt HUD) |
| Primary text | `#FFFFFF` | Bitmap HUD text |
| Muted | `#98989D` | Inactive labels |
| Panel / faint | `#1C1C1E` / `#48484A` | Stone-dark frames |

## Master prompt (EN)

```
Mobile UI for cycle tracker "Rhythma" in the style of the 1997 PC game Blood
(Monolith, Build engine): low-res pixel art, chunky bitmap fonts, jagged aliased
edges, dark gothic FPS title/menu/HUD aesthetic, CRT-ish darkness, simple
ornamental pixel frames. Adult, grim, restrained — NOT cute, NOT teenage.

NO gore, NO corpses, NO weapons, NO violence, NO body horror.

Palette ONLY: bg #0A0A0A, blood-magenta accent #FF10F0, cyan #5ECAD6,
white text, gray #98989D, dark panels #1C1C1E.

Tabs: Today · Year · Settings. iPhone portrait.
```

## Negative prompt

```
gore, blood splatters on UI, corpses, weapons, violence, cute doodles, hearts,
smileys, modern iOS glossy UI, glassmorphism, soft shadows, luxury minimalism,
handwriting diary, brush lettering, pastel
```
