# Rhythma

Мінімалістичний Expo-застосунок: життя в ритмі циклу. Дані лишаються на телефоні.

Сьогодні — одна з чотирьох фаз і коротка підказка. Кільце фіксує перший день. Рік — 12 рядків крапок; **сезони** вмикають прогноз.

```bash
npm install
npx expo start
```

```bash
npm test
npx tsc --noEmit
```
