# Rhythma

Мобільний Expo-застосунок для відстеження циклу. Дані лишаються на телефоні.

## Можливості

- Кнопка **Перший день місячних** — фіксує сьогоднішню дату
- Річний календар — 12 місяців, натискання на день додає або прибирає перший день
- Опційно: овуляція, фертильне вікно і прогноз наступних місячних за середньою довжиною циклу
- Зберігання через AsyncStorage, без облікового запису і без сервера

## Запуск

```bash
npm install
npx expo start
```

Відкрийте проєкт у [Expo Go](https://expo.dev/go) (QR-код у терміналі) або в симуляторі:

```bash
npm run android
npm run ios
npm run web
```

## Перевірки
