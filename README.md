# Rhythma

Мінімалістичний Expo-застосунок: життя в ритмі циклу. Дані лишаються на телефоні.

Сьогодні — одна з чотирьох фаз (зима, весна, літо, осінь) і коротка підказка, як синхронізувати плани. Кнопка фіксує перший день місячних. Річний календар тихий; опційно показує сезони й прогноз.

```bash
npm install
npx expo start
```

```bash
npm test
npx tsc --noEmit
```
