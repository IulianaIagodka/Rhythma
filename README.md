# Rhythma

Лог циклу + звірка навантаження з календарем. Дані на телефоні.

- Кнопка **Місячні почалися сьогодні**
- Тиждень: рожеве — цикл, бірюзове — події та тренування з календаря
- Рекомендація: чи навантаження відповідає фазі циклу
- Річний календар записів

```bash
npm install
npx expo start
```

```bash
npm test
npx tsc --noEmit
```
